# HPC.nrw intensive beratung

This branch contains code changes and code snippets related to the intensive Beratung
discussions. These discussions considered the code performance and worked to
develop insights on factors that most affect the code's performance.

Code "contributions" are added in two general locations:
1. `multicharge-hacks/snippets` contains small programs or code fragments to
   demonstrate approaches.
2. `multicharge-hacks/src` contains the original source code with changes
   to measure the impact on performance of alternative ways of coding
   something.

Please, look in the respective locations for more details on the codes and changes,
the experiments performed, and outcomes.
